# Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript.

## Features

- Search weather by city
- Use current device location
- Display current temperature
- Display weather conditions
- Display humidity
- Display wind speed
- Responsive design
- Weather data fetched from Open-Meteo API

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Geolocation API
- Git
- GitHub

## How It Works

Users can enter a city name to search for its current weather.

The application also provides a **Use My Location** option that uses the browser's Geolocation API to obtain the user's coordinates and display the weather for that location.
